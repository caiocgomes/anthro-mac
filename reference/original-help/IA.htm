The Individual assessment module facilitates the collection of longitudinal data of children and adolescents from birth to 19 years whose growth is being monitored over time.

The software calculates z-scores and percentiles for the indicators weight-for-age, length/height-for-age and BMI-for-age. For children 0-60 months the programme uses the WHO child growth standards, and for older children 61 months to 19 years the WHO reference 2007.

When opening this module, the list of example children appears on the left column and the child-specific section to the right is blank.

To add a new child click on .

To select a child, either highlight or tick on the box next to the name. The user can open, delete, archive a selected child using the icons on top or select the function under Individual assessment. This menu bar offers additional functions, e.g. Options or Manage additional data (for further information please see the manual).

To archive one or several children, select by ticking the box in front of the child's name and click on . The children disappear from the active list and are moved into the archive. To restore a child from the archive, click on  to view the archived children, select the child(ren) you want to retrieve and click on .  

To search for a child, click on  and enter the search criteria, e.g. name of the child, sex, ID or date of birth. The name fields are not case-sensitive and "*" can be used as a wildcard if the full name is unknown, e.g. entering [L*] will find Lopez.

When opening a child's record, all his/her visit data appear on the specific window section. To open an existing visit doubleclick on the respective row or highlight the row and click on . The user can edit the visit data and save or cancel the changes.

Results in z-scores and percentiles pertaining to the selected visit are displayed in the lower part of the child window. Colour codes related to severity levels alert the user if a child falls beyond certain cut-off limits, e.g. red between 2 and 3 SD, and black beyond 3 SD below or above the WHO standard/reference median.
 
To view the graphic display, click on . Indicator-specific graphs can be selected from the drop down menu of any open display. To change from z-score (default) to percentile classification or from single-point to multiple points display use respective drop down menu. Additional features enable to zoom-in, copy and print the graph (see manual).

In the child window the user can add a new visit, delete a visit or go to the graphs pertaining to the highlighted row of the child's visit data.

To add a new visit click on . This will open an empty data-entry window.

To save, click on .

To cancel any data changes to a visit, click on .

These three functions can also be activated via the menu bar Selected child.

Click on  to generate the selected child's report with the anthropometric raw measurements and results for all visits in *.TXT format and specify where to save this report.

The user can save the exported file in *.CSV, *.TXT and *.XML file formats. XML is the acceptable file format for importing data into this module (for further details please see manual).   

The menu icons on the top right work as in any other MS application and enable the user to minimize, resize to fill the screen and close the module.
