The Nutritional survey module enables the user to:

  • collect new nutritional data based on a sample of children (one record per child)

  • open, edit, save and delete existing surveys

  • move surveys temporarily into the archive and retrieve from archive

  • import survey data files in  *.DBF, *.CSV, *.REC, *.TXT or *.XML formats (for details please see manual)

  • export survey data files in *.CSV, *.TXT and *.XML formats (for details please see manual)

  • analyze anthropometric measurements using the WHO child growth standards for 0-60 month olds and WHO reference 2007 for 61 month-19 year olds

  • perform cluster analysis to correct the 95% confidence intervals (CIs) for the cluster sampling design

  • produce standardized outputs of these analyses' results with or without 95% CIs

When opening the module, the column to the left shows the built-in example survey. Functions related to survey data sets can be activated via the icons on top of the list or via the menu bar under Nutritional survey.

To add a new survey, click on . The window to the right becomes activated and the user should enter a survey name on top (notes are optional). Child records can be added by clicking   and completing the New record window and confirming with the <Save> button. The added child record appears on the spreadsheet and the lower part of the window shows the results in percentiles and z-scores.

Colour codes related to severity levels alert the user if a child's measurement lies beyond certain cut-off limits. For example, the colour is red between 2 and 3 SD, and black beyond 3 SD below or above the WHO standard/reference median.

To view the graphic display, click on . Indicator-specific graphs can be selected from the drop down menu of any open display. To change from z-score (default) to percentile classification, use respective drop down menu. Additional features enable to zoom-in, copy and print the graph (see manual).

When the user selects a survey from the list on the left and clicks on , all child records in this survey appear in the open survey window section to the right with the results in z-scores and percentiles of the highlighted child record displayed at the bottom.

To import a survey, select the action from the Nutritional survey menu bar and choose the file you want to import.

To export any survey, select first by ticking the box next to the survey's name and then choose the required action from the Nutritional survey menu bar.

Software functionalities related to the currently selected /open survey can be activated via icons at the top or via the menu bar under Current survey. It is important to save any changes in the current survey before opening another survey or closing the module.

By clicking the iterative filter function  the user can select a sub-sample of the current survey for further analysis; clicking on  clears the filter.

To access further Options click on . Here the user can specify, for example, ID assignment and age groupings as well as adjust the z-score ranges admitted in the analysis. To confirm changes, click on <OK>. To return to default settings, click on <Reset>.

The user can select several child records by holding down left mouse click and dragging over rows or by using the CTRL key and the left mouse click. To copy them to the clipboard click on . These records can then be inserted into any other spreadsheet, such as EXCEL.  

There are several data analysis options:

To generate a standard report click on : This report includes for each indicator all children with a plausible z-score to produce prevalence estimates by age groups and by sex with 95%CIs, summary statistics and weighted Ns. The user can further specify in case the survey is based on a cluster sample to derive improved analysis in order to correct the 95% CIs for this specific sampling design.

To generate a summary report of the estimates click on : This report includes for each indicator all children with a plausible z-score to produce prevalence estimates by age groups and by sex, with summary statistics and weighted Ns according to the EXCEL data-entry format shown on www.who.int/growthref/tools. It does not include 95% CIs.

The menu icons on the top right work as in any other MS application and enable the user to minimize, resize to fill the screen and close the module.
