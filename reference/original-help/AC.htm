The Anthropometric calculator module enables the user to derive nutritional status information for  individuals based on the WHO standards when 0-60 months old and based on the WHO reference 2007 when 61 months to 19 years old. The software calculates z-scores and percentiles for the indicators weight-for-age, length/height-for-age and BMI-for-age.

For children 0-60 months old the user has to specify whether recumbent length or standing height was measured by clicking the relevant radio button. Given that children 61 months and older should be measured standing, height is assumed and no button needs to be ticked.

The software derives the child's age based on his/her date of birth and date of visit. If the exact birth day is unknown, the user can tick the box next to "Approximate date". The software will then automatically insert a randomized day within the given month.

The programme's default status is that a child has no oedema. In case the observer assesses a child as having oedema, his/her weight data would be flawed and thus the user is advised to specify that condition by ticking the respective radio button. In that case only length/height-for-age results are displayed.

Note that in this module the user cannot save any information. To keep a copy of the screen image, press the <ALT+Print Screen> keys and paste the image into e.g. a Microsoft (MS) Word file.

Colour codes related to severity levels alert the user if a child's measurement lies beyond certain cut-off limits. For example, the colour is red between 2 and 3 SD, and black beyond 3 SD below or above the WHO standard/reference median.

Clicking on  next to the z-score values for each indicator opens a graphic display of the measurement.

The top menu bar provides additional features:

While holding down the left mouse click, drag the mouse until the desired area of the graph is selected. When releasing the left mouse click this selected area will appear enlarged. To return to the original dimension, click on .

To copy the image, click on  and then select paste or CRTL+V to insert the image into a document or slide.

To print the graph, click on  on top menu bar.

Indicator-specific graphs can be selected from the drop down menu of any open display. To change from z-score (default) to percentile classification, use respective drop down menu.

The menu icons on the top right work as in any other MS application and enable the user to minimize and close the module. Resizing to fill the screen is not possible.
